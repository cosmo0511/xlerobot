양팔 이동 조작 정책의 조작 성능과
언어 지시 추종의 괴리

Dissociation between Manipulation Performance and Language Instruction Following in a Bimanual Mobile Manipulation Policy
김미송*, 김송연*, 최명기*, 김현우†, 조혜경**한성대학교 AI응용학과   †주식회사 로보시지
연구 배경 및 목적Background
그림 1. 실기 평가 장면 — 빨간 주사위를 집어 바구니로
  • 저가형 VLA 평가는 고정형 단팔 중심[1] — 이동 베이스 + 양팔 통합 정책 평가는 드묾[4]
  • 높은 조작 성공률 ≠ 언어 지시 추종 — 최근 제기되는 문제[5–8]
  • 양팔 로봇은 목표 물체에 따라 팔을 골라야 함 → 언어가 행동 결정에 반영되는지 직접 확인 가능
RQ1
SmolVLA[2]가 ACT[3]보다 높은 조작 성능을 보이는가?
RQ2
언어 지시에 따라 올바른 팔을 선택하는가?
  • 추가 분석: 팔 선택 분기 직전 언어·영상·관절 입력을 하나씩 교체 → 정책이 무엇에 반응하는지 확인
시스템 구성System
  • SO-ARM101 양팔 + 3옴니휠 베이스(XLeRobot[9]), 카메라 4대
  • 행동·관측 상태 15차원 — 양팔 관절 12 + 베이스 속도 3, 학습·추론은 LeRobot[10]
그림 2. 분산 제어 구조 — 무선은 평균 812 ms 지연으로 관측 갱신 불가 → 모든 평가는 유선(왕복 평균 2.8 ms)·30 Hz 고정
과제 및 실험 설정Task & Methods
  • 좌·우 출발 위치 중 한 곳에서 시작 → 1 m 앞 책상까지 이동
  • 빨강·노랑 주사위 중 지시된 색을 그쪽 팔로 집어 바구니에 투입
그림 3. 같은 장면이라도 색 단어 하나로 써야 할 팔이 바뀜 — 두 주사위가 늘 함께 있어 영상만으로는 대상 결정 불가 (좌우 배치는 시행마다 바뀜)
데이터
텔레오퍼레이션 104 에피소드(평균 38.2초), 색상 × 팔 26/26/26/26 균등
분기
두 팔 동작은 중앙값 23.6초에 갈라짐 — 그 전까지 행동 동일
학습
ACT · SmolVLA 동일 데이터, batch 16, 80k 스텝
평가
모델당 40회 (배치 2 × 시작 위치 2 × 지시 2, 각 5회), Fisher 정확검정
왜 언어가 불리한가
  • 언어로 설명되는 행동 차이는 23.6초 이후에만 존재
  • 영상·관절 상태는 처음부터 끝까지 오차 감소에 기여
  • 관절값을 그대로 복사만 해도 오차 6.741 → 1.555 (정책이 줄인 오차의 84%)[11]
연구 결과Results
단계별 성공률 (모델당 40회)
그림 4. ACT는 언어 입력을 받지 않으므로 지시 색상 일치는 SmolVLA만 해당
  • SmolVLA, 조작 네 단계 모두 ACT보다 유의하게 높음 → RQ1 확인
  • 그러나 지시 색상 일치는 50.0%에 그침
    • 8개 조건 전부 지시와 무관하게 오른쪽 주사위 파지 — 배치가 좌우 균형이라 산술적으로 50%
  • ACT도 팔이 움직인 34회 중 32회(94.1%)가 오른팔
입력 민감도 분석Input Swap
  • 학습 데이터 104 에피소드에서 입력을 하나씩 교체해 예측 팔 변화 측정
  • 대상: 분기 직전 312 장면 (로봇은 움직이지 않음)
입력 교체 시 예측 팔이 뒤집힌 비율 (%)
그림 5. 잡음은 난수 시드만, 나머지는 짝 에피소드에서 그 입력만 가져와 교체
바꾼 입력정답 팔이 바뀌어야 하나이상값실제
잡음 (난수 시드)아니오0%0.6%
지시문 (반대 색)예100%1.3%
영상 (반대 배치)예100%58.7%
관절 상태 (반대 배치)아니오0%45.2%

관절 상태 (같은 배치)아니오0%47.8%
반대 배치 짝 = 같은 색 지시·반대 팔 / 같은 배치 짝 = 배치 동일·다른 지시. 분기 전이라 팔이 아직 움직이지 않았고(중앙값 0.1°), 관절 상태에는 주사위의 색·위치 정보가 없음
언어
기대값 100% → 실제 1.3%, 잡음 기준(0.6%)과 같은 수준
배치
영상 58.7% 중 배치 기여분은 7.4%p(= 58.7 − 51.3)뿐
관절
45.2% vs 47.8% — 배치와 무관, 다른 요인에 반응
전체
네 값 모두 50% 부근 — 지배적 입력 없이 하나만 바꿔도 결정이 흔들림
결론 및 시사점Conclusion
  • SmolVLA는 조작 네 단계 모두 ACT보다 유의하게 우세(RQ1) — 그러나 지시 색상 일치 50.0%, 40회 모두 오른팔 사용(RQ2)
  • 입력 교체 시 지시문 변경엔 거의 무반응, 영상·관절 상태 변경엔 크게 반응
  • 배치가 같은 장면으로 바꿔도 절반이 뒤집힘 → 에피소드별 장면·자세의 미세한 차이에 의존 가능성
  • 구조가 다른 두 정책이 같은 쏠림 → 특정 모델이 아닌, 행동과 관측 상태가 동일 변수로 구성되는 데이터 수집 방식에서 비롯됨을 시사
